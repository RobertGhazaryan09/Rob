# SocialNet — Исходный код проекта

Современная социальная сеть с регистрацией, авторизацией, профилями пользователей и базой данных MySQL.

## Структура файлов в этой папке

### 1. База данных
- **`init.sql`** — Полный SQL-скрипт создания базы данных `social_network`, таблицы `users` с ограничениями `UNIQUE` и автоинкрементом, а также примерами всех используемых запросов (`INSERT`, `SELECT`, `WHERE ... LIKE`, `DELETE`).

### 2. Бэкенд (Node.js & Express)
- **`server.ts`** — Главный сервер приложения:
  - Регистрация с проверкой дубликатов логина и email, хешированием паролей через bcrypt (`/api/auth/register`)
  - Вход пользователей со сверкой bcrypt-хешей и выдачей JWT (`/api/auth/login`)
  - Получение текущего пользователя (`/api/auth/me`)
  - Поиск и список пользователей с параметризованным SQL-запросом `WHERE username LIKE ? OR email LIKE ?` (`/api/users`)
  - Удаление только собственного профиля `DELETE FROM users WHERE id = ?` (`/api/users/me`)
- **`db.ts`** — Модуль подключения к MySQL через пул соединений `mysql2/promise` с поддержкой автоматической инициализации таблицы при старте.

### 3. Фронтенд (React & Tailwind CSS) — папка `frontend/`
- **`App.tsx`** — Главный координирующий компонент (управление авторизацией, состояние сессии, поиск, уведомления).
- **`Navbar.tsx`** — Верхняя панель в стиле Instagram/Facebook с кнопками «Войти», «Зарегистрироваться», аватаром и кнопками обновления и выхода.
- **`LoginForm.tsx`** — Форма входа в аккаунт с переключателем видимости пароля.
- **`RegisterForm.tsx`** — Форма регистрации нового пользователя с полной валидацией.
- **`UserDirectory.tsx`** — Каталог зарегистрированных пользователей (таблица на широких экранах и карточки для мобильных телефонов Android), строка поиска и кнопка «Удалить мой профиль».
- **`types.ts`** — TypeScript интерфейсы моделей данных (`User`, `DatabaseStatus`).
- **`index.html`** — Главная страница приложения.

### 4. Конфигурация
- **`package.json`** — Список библиотек и скриптов запуска.
- **`.env.example`** — Пример конфигурации переменных окружения для подключения к MySQL.
